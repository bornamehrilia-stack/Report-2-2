### ۱. هدف آزمایش

آموزش نحوه برقراری ارتباط بین برد آردوینو و رایانه، ارسال داده‌ها از طریق پورت USB و مشاهده خروجی در محیط **Serial Monitor**.

### ۲. شرح مختصر آزمایش

در این مرحله، هدف کنترل قطعه فیزیکی نیست، بلکه ایجاد یک پل ارتباطی متنی است. با استفاده از این قابلیت، ریزپردازنده پیام "Hello, World!" را تولید کرده و از طریق درگاه سریال به رایانه می‌فرستد. این تکنیک پایه و اساس نمایش مقادیر سنسورها در پروژه‌های پیچیده‌تر است.

### ۳. موارد مورد نیاز

* برد **Arduino Uno**
* کابل USB (جهت انتقال داده و تغذیه)


### ۴. نمایش کد پروژه

```cpp
void setup() {
  // راه‌اندازی ارتباط سریال با نرخ انتقال 9600 بیت بر ثانیه
  Serial.begin(9600);
}

void loop() {
  // ارسال متن به خروجی سریال همراه با رفتن به خط بعد
  Serial.println("Hello, World!");
  
  // ایجاد وقفه یک ثانیه‌ای بین هر ارسال
  delay(1000);
}

```

### ۵. توضیح مختصر کد

* **`Serial.begin(9600)`**: این دستور در بخش `setup` برای تعیین سرعت تبادل داده (Baud Rate) استفاده می‌شود. عدد ۹۶۰۰ سرعت استاندارد برای اکثر پروژه‌های آردوینو است.
* **`Serial.println`**: این تابع رشته متنی داخل گیومه را به پورت سریال می‌فرستد. پسوند `ln` (مخفف line) باعث می‌شود که بعد از چاپ هر پیام، مکان‌نما به خط جدید برود.
* **عملکرد تکرار شونده**: به دلیل قرار گرفتن دستور در حلقه `loop` و وجود تاخیر یک ثانیه‌ای، پیام شما به صورت مداوم و هر ثانیه یک‌بار در مانیتور نمایش داده می‌شود.
